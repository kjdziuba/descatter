# descatter

Physics-informed generative correction of resonant Mie scattering (RMieS) in
infrared tissue spectra. This is a research sandbox in Krzysztof Dziuba's PhD
(University of Manchester).

Start with `CLAUDE.md`. For the science, read `docs/RESEARCH_BRIEF.md`. For
what is being tested and its status, read `docs/EXPERIMENTS.md`.

Work is split across three Claude sessions (mac, watford, chat) that
coordinate through this repo. See `docs/COMMS.md`.
