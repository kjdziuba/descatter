# legacy/

This folder holds reference code that new code is checked against. It is not
developed here.

- `rmies_sim.py` is the Lesson 1 simulator from the Spectra Research course:
  14 Lorentz oscillators, van de Hulst ADA sphere and the diagnostics
  `amide_i_position`, `scatter_proxy`, `confound_check` and `stress_test`.
  Chris adds it here if he has the file. E1's unit tests reproduce its numbers
  when it is present.
